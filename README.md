# وفّري

مقارنة أسعار أجهزة البيت عبر متاجر مصر: غسالات، ثلاجات، تكييف، قلايات، مراوح، عناية شخصية، وأثاث. كل منتج كارت موحّد، والأرخص ظاهر، والعمولة من روابط الأفلييت.

النسخة MVP تفاعلية بكتالوج تجريبي. **شبكة المتاجر** على `/stores` بتجمع ماركتبليس وسلاسل أجهزة وهايبر وعلامات رسمية وموزّعين، مع حالة الربط (متصل / أفلييت جاهز / فيد رسمي / تواصل). التوسعة على عروض الأسعار بتتم حسب فئة الجهاز لكل متجر متوافق — من غير سكرابينج كعمود فقري.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://127.0.0.1:43147](http://127.0.0.1:43147).

واجهة الشبكة JSON: [http://127.0.0.1:43147/api/network](http://127.0.0.1:43147/api/network).

## الصفحات

| المسار | الوظيفة |
| --- | --- |
| `/` | الرئيسية والبحث |
| `/search` | السوق والفلاتر |
| `/product/[id]` | مقارنة كل المتاجر المتصلة بالمنتج |
| `/list` | قايمة الجهاز / أجهزة الحياة اليومية |
| `/stores` | شبكة الإيكوميرس وحالة كل موصل |
| `/live` | مراقبة لحظية للفروق والنوتيفيكيشن |
| `/alerts` | أهداف السعر وصندوق الوارد |
| `/how-it-works` | طرق الربط والأفلييت |

القايمة والتنبيهات والمقارنة تتحفظ في `localStorage`.

## المكدس

Next.js (App Router) + TypeScript + Tailwind + shadcn/ui.

# وفّري

ماركتبليس تجميع للعروسة في مصر **ومخطِّط جهاز**: من الخطوبة ليوم الفرح لتجهيز البيت لأول شهر وبعد الجواز. مش محل بيبيع الجهاز — طبقة مقارنة + رحلة تسوّق حسب الميزانية والشقة.

## الحساب

[`/register`](http://127.0.0.1:43147/register): تسجيل تفصيلي (الاسم، العريس، المحافظة، الفرح، الشقة، الميزانية). [`/login`](http://127.0.0.1:43147/login) الدخول. الحساب للتجربة على المتصفح (localStorage) — مفيش سيرفر مصادقة لسه.

## رحلة العروسة

[`/plan`](http://127.0.0.1:43147/plan): تاريخ الفرح، الميزانية، التشطيب، المطبخ، الأجهزة، عدد الغرف. الخطة تشيل اللي موجود، توزّع ضروري / مهم / رفاهيات، وتعرض اقتصادي / متوسط / فاخر لكل بند، مع جدول شهر بشهر. باكدج الجهاز بيتبني أوتوماتيك حسب الإجابات. الأسعار تقدير تخطيط.

## احتياجات العروسة

[`/needs`](http://127.0.0.1:43147/needs): قاعدة بنود على خمس مراحل (خدمات فرح، لبس وتجميل، مطبخ ورفايع، أجهزة، غرف، تنظيف، بيت ذكي، شهر عسل، بوكس أول 30 يوم، تركيب وصيانة، هدايا وتخصيص). كل بند يتربط بخريطة المصادر.

## خريطة المصادر

[`/sourcing`](http://127.0.0.1:43147/sourcing): لكل فئة ثلاث طبقات: أونلاين، أسواق الجملة، مصانع. طبقات الجهاز: اقتصادي / متوسط / فاخر / جهاز كامل.

## خريطة الشراء

[`/map`](http://127.0.0.1:43147/map) فيها مراحل تفصيلية (فستان، مكياج، أجهزة، رفايع…). الأحياء في حالة تواصل: ظاهرة من غير أسعار ملفّقة.

## أماكن الأحياء

[`/places`](http://127.0.0.1:43147/places): البحث بيرمي العميلة على الحي المناسب من داتا وفّري — من غير Google Search ولا Places API.

## دليل المنتجات والفيد

[`/guide`](http://127.0.0.1:43147/guide) قايمة بنود + بوكسات. [`/ingest`](http://127.0.0.1:43147/ingest) سحب CSV/JSON مصرّح. صفحات HTML للمتاجر مش بتتسحب.

البحث في [`/search`](http://127.0.0.1:43147/search) مربوط بشبكة متاجر مصرية (ماركتبليس وسلاسل وأفلييت). كل منتج يعرض عروض البائعين مع فلاتر السعر والتقييم والمراجعات والخصم والتوفر والتوصيل. الأسعار المرجعية مش زحف لحظي لكل الإيكومرس المصري. [`/list`](http://127.0.0.1:43147/list) يحفظ جهاز العروسة ويصدّر CSV للجهاز أو لكل البائعين.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://127.0.0.1:43147](http://127.0.0.1:43147).

## الصفحات

| المسار | الوظيفة |
| --- | --- |
| `/` | الرئيسية — تعريف بالسيستم (سكاشن وأنيميشن، من غير كتالوج) |
| `/register` | تسجيل عروسة تفصيلي |
| `/login` | دخول |
| `/account` | بيانات الحساب |
| `/plan` | رحلة العروسة + باكدج الجهاز |
| `/needs` | قاعدة الاحتياجات على 5 مراحل |
| `/sourcing` | أونلاين + جملة + مصنع |
| `/map` | خريطة المراحل |
| `/places` | أماكن وأحياء |
| `/guide` | دليل البنود والبوكسات |
| `/search` | بحث سوق مصر: منتج/فئة، فلاتر سعر وتقييم وخصم وتوفر وبائع، وكل العروض جنب بعض |
| `/list` | جهاز العروسة: حفظ قوائم، اختيار بائع، تصدير الجهاز أو ملف كل البائعين |
| `/admin` | صحة المراقبة: نجح/فشل/معلّق |
| `/legal` | امتثال، robots، بيانات واقعية فقط |
| `/plans` | سقف روابط محلي (Starter→Enterprise) |
| `/stores` | المصادر وحقوقهم |
| `/live` | أسعار حية من الموصّلات (فيد / API / JSON-LD) |
| `/ingest` | فيد المصدر + أفلييت + كل الموصّلات |
| `/connectors` | APIs وطرق جلب السعر الحي |

وفّري مش بتحجز قاعة ولا تركّب تكييف بنفسها — بتوجّه للمصدر والحي.

أزرار الشراء: جوميا بتفتح بحث الكتالوج على jumia.com.eg. تريدلاين على tradelinestores.com (tradeline.com.eg مش مسجّل DNS). كارفور ونون وأمازون بتفتح بحث جوجل. مش بنولّد صفحات وهمية زي `/p/lg-washer-8`.

صور الأجهزة في الكتالوج من [ويكيميديا كومنز](https://commons.wikimedia.org) (رخصة حرة) — مش صور صفحة المنتج عند التاجر.

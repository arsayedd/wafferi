# وفّري

مقارنة أسعار جهاز العروسة وكل رفايع أول بيت عبر متاجر مصر. مش متجر: طبقة مقارنة فوق جوميا ونون وكارفور والشركات المتصلة.

## دليل العروسة

صفحة [`/guide`](http://127.0.0.1:43147/guide) فيها **18 بابًا** من تجهيز المطبخ لبوكس الطوارئ وحاجات الأطفال المستقبلية، مع **بوكسات جاهزة**:

- بوكس رفايع المطبخ
- بوكس تنظيم البيت
- بوكس الحمام
- بوكس العناية بالعروسة
- بوكس شهر العسل
- بوكس أول بيت
- بوكس التنظيف
- بوكس القهوة والشاي
- بوكس الرفايع كامل
- العروسة Full Package

كل بند منتج موحّد بـ 2–3 عروض أسعار تجريبية (من غير توسيع وهمي على كل الشبكة). الربط الحي يتم بأفلييت وفيد تاجر رسمي، مش سكرابينج.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://127.0.0.1:43147](http://127.0.0.1:43147).

## الصفحات

| المسار | الوظيفة |
| --- | --- |
| `/` | الرئيسية |
| `/guide` | دليل العروسة الكامل والبوكسات |
| `/search` | السوق والفلاتر |
| `/product/[id]` | مقارنة المتاجر |
| `/list` | قايمة الجهاز والميزانية |
| `/stores` | شبكة المتاجر |
| `/live` | مراقبة لحظية تجريبية |
| `/ingest` | استيراد فيد تاجر (CSV/JSON) |
| `/how-it-works` | الأفلييت والعمولة |

القايمة والتنبيهات تتحفظ في `localStorage`.

## المكدس

Next.js (App Router) + TypeScript + Tailwind + shadcn/ui.

# وفّري

ماركتبليس تجميع للعروسة في مصر: من الخطوبة لفستان الفرح لأجهزة البيت ورفايع حمام التلات. مش محل بيبيع الجهاز — طبقة مقارنة فوق المتاجر المتصلة، وخريطة للأحياء اللي السعر بيتقارن فيها على الطبيعة.

## خريطة الشراء

[`/map`](http://127.0.0.1:43147/map) فيها **21 مرحلة**: خطوبة، فستان، إكسسوار، مكياج، عناية، لانجري، لبس، أحذية وشنط، شهر عسل، أجهزة، مطبخ، رفايع مطبخ، مفروشات، حمام، تنظيف، تنظيم، ديكور، سفرة، عطور بيت، هدايا، طوارئ.

المصادر تشمل وان ستوب (صيدناوي، سيتي ستايل، جوميا، نون، أمازون، كارفور، هايبر وان، سبينيس، كازيون، مترو، التوحيد والنور) وأحياء الجملة (عبدالعزيز، العتبة، حمام التلات، شبرا، النزهة، الموسكي…) وبوتيكات الفساتين والصاغة والصيدليات.

الأحياء في حالة **تواصل**: ظاهرة على الخريطة من غير أسعار ملفّقة. الربط الحي للأونلاين بأفلييت أو فيد تاجر.

## دليل المنتجات

[`/guide`](http://127.0.0.1:43147/guide) قايمة بنود + بوكسات جاهزة للجهاز.

## أماكن الأحياء

[`/places`](http://127.0.0.1:43147/places): أحياء الجملة (حمام التلات، عبدالعزيز، العتبة، دمياط، الصاغة…). البحث بيرمي العميلة على الحي المناسب من داتا وفّري — من غير Google Search ولا Places API.

## فيد المصدر والأفلييت

[`/ingest`](http://127.0.0.1:43147/ingest): سحب CSV/JSON من رابط فيد مصرّح، ظهور اسم المصدر على كل عرض، ولينك خروج بأفلييت وكوبون تظبطيهم لكل متجر. صفحات HTML للمتاجر مش بتتسحب.

## البحث

`/search` فيه مسارين:

1. منتجات وفّري الأونلاين.
2. لو عايزة تنزلي: الحي المناسب من داتا الأحياء (حلل → حمام التلات، غسالة → عبدالعزيز، ذهب → الصاغة).

مفيش مفاتيح جوجل. انسخِي `.env.example` لو حابة؛ التشغيل يشتغل من غيره.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://127.0.0.1:43147](http://127.0.0.1:43147).

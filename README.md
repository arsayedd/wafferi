# وفّري

مقارنة أسعار **جهاز العروسة** عبر متاجر مصر: بحث، فلاتر ماركة ومتجر وسعر، كارت منتج موحّد، قايمة جهاز بميزانية، تنبيهات، ومقارنة جنب جنب. العمولة من روابط الأفلييت التجريبية.

النسخة دي MVP تفاعلية بكتالوج تجريبي (مش أسعار لايف). الربط الحقيقي هيتم عبر برامج جوميا ونون وArabClicks ثم الشراكات المباشرة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://127.0.0.1:43147](http://127.0.0.1:43147).

## الصفحات

| المسار | الوظيفة |
| --- | --- |
| `/` | الرئيسية والبحث والقايمات الجاهزة |
| `/search` | السوق والفلاتر |
| `/product/[id]` | مقارنة المتاجر + التقييمات |
| `/list` | قايمة الجهاز والميزانية |
| `/deals` | أكبر فرق سعر |
| `/stores` و `/brands` | الشركاء والماركات |
| `/matching` | محرك توحيد المنتجات |
| `/how-it-works` | الأفلييت ومصادر البيانات |

القايمة والتنبيهات والمقارنة تتحفظ في `localStorage` على الجهاز.

## المكدس

Next.js (App Router) + TypeScript + Tailwind + shadcn/ui.
